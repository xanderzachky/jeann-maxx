# JEANN MAXX

JEANN MAXX adalah alat tuning performa Android open-source yang dirancang untuk memaksimalkan frame rate dan efisiensi daya.

## Fitur Utama
- Arsitektur tiga tingkat: Root, Shizuku, dan Non-Root.
- Zero Telemetry: Semua data diproses secara lokal.
- Revert Journal: Sistem pemulihan otomatis jika terjadi crash.
- Boot Watchdog: Rollback otomatis ke konfigurasi aman saat boot loop.

## Struktur Folder
- /src: Kode sumber utama (Kotlin/Compose).
- /docs: Dokumentasi teknis.
- /.github: Alur kerja CI/CD.

## Instalasi
1. Clone repositori ini.
2. Pastikan Android SDK terpasang.
3. Jalankan './gradlew assembleDebug'.
